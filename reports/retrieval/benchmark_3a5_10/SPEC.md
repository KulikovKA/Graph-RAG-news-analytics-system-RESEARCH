# Stage 3A.5.10 · генерация по Graph-RAG C

Проверяется гипотеза, что замороженный Top-5 production C можно передать Groq и получить ответ с проверяемыми ссылками на исходные окна. Если список путей или их provenance отличается на том же входе, ссылка не разрешается до точного фрагмента или модель отвечает фактом при отсутствии опоры, соответствующий критерий не выполнен.

Базовый контроль — Stage 3A.5.9 с решением KEEP_C. Контроль генеративного интерфейса — минимальный API-запрос и локальный mock. Сравнение с LLM без RAG и Vector RAG отложено. Замороженные 30 abstracts и document lock идентифицируются хешами из PROFILE.json. Используются окна уже разрешённого корпуса OpenAlex. Нового сбора, переиздания текстов и присвоения лицензий нет. Benchmark Gold, исторический holdout и поля оценивания исключены из входов генерации. Replay разрешён только для approved A/B/C production-строк. Вопросы демонстрации выбираются до генерации. Настройка на их ответах не проводится.

Профиль, граф, снимок, код и модели NER/E5 закреплены Stage 3A.5.9. Локальный inference — CPU, одна последовательная очередь, 4 потока и seed 42. Настройки генерации, версия шаблонов, модель, tokenizer SHA и доступные идентификаторы провайдера записываются в артефакт. Стандартная модель проверяется по каталогу Groq, значения задаёт конфигурация. Бюджет smoke — максимум 10 отправок chat/completions с учётом повторов, 6000 входных и 1000 выходных токенов на отправку по умолчанию. В smoke повторы отключены. Денежная стоимость приводится только при закреплённом тарифе. API может менять backend, дословная повторяемость не гарантируется.

## Дизайн и границы

Адаптер retrieval создаёт единый упорядоченный интерфейс путей для live и replay. Live оборачивает имеющиеся QueryAnalyzer, EntityLinker, GraphRetriever, EvidenceExtractor и rerank_paths. Replay читает только сохранённый индекс порядков и source registry, проверяет upstream hashes, выбирает вопрос по digest. Context Builder сверяет оригинал по frozen corpus, собирает ссылки и целиком исключает окна сверх бюджета. Модель возвращает JSON с блоками утверждений, citation IDs и ограничениями. Валидатор восстанавливает метаданные ссылок только из переданного контекста. Результат CLI разделяет отсутствие доказательств и отказ инфраструктуры. Локальные результаты пишутся отдельными файлами без перезаписи. Восстановление после сбоя — повтор с новым выходным путём. Stage 3A.5.9 и замороженный namespace служат входами для чтения.

Критерии остановки smoke — лимит запросов, ошибка авторизации, недоступность модели или повторяемый инфраструктурный сбой. Угрозы валидности — ложные связи, пропуски retrieval, необоснованные утверждения модели, provenance при верном offset, недетерминированность API, малая нерепрезентативная выборка. Работу продолжают локальными и replay-проверками при недоступном Neo4j. Состояния проверок фиксируются как PASS, FAIL, BLOCKED, NOT RUN.
