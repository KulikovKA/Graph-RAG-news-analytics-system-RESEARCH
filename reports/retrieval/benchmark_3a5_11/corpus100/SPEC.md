# Stage 3A.5.11.1 · Corpus100 · v1

## SPEC

План-источник — [STAGE_3A5_11_PLAN.md](../../benchmark_3a5_10/STAGE_3A5_11_PLAN.md). Исторический контроль — [30 аннотаций](../../../ner_v2/research_run2/corpus_manifest.json), замороженных до inference. Здесь проверяется гипотеза, что целевой тематический отбор даст десять двухстатейных внутритематических сравнений и не менее четырёх межтематических связок, охватывающих все пять тем. Каждую связку проверяем чтением двух аннотаций, отмечая общую ось и различие контекстов или результатов. Альтернативы — исторический разнотематический отбор и тематический отбор без проверки связок. Сравнение качества retrieval с ними отложено, статистический вывод об улучшении не предусмотрен.

Включаем англоязычные статьи журналов 2018–2025 годов с DOI, OpenAlex ID и PMC ID. В каждом тексте должны читаться задача, метод или данные и результат либо ограничение. Допускаем 80–600 слов (разбиение по пробельным символам), минимум три границы предложений, без маркеров повреждения. Пригодность проверяется при чтении. В биотехнологиях рассматриваем промышленные процессы и переработку биомассы.

Europe PMC находит кандидатов по заголовкам и аннотациям и даёт XML издателя. [OpenAlex](https://help.openalex.org/data/works/attributes/) подтверждает идентичность работы по DOI и даёт библиографию. Для точного текстового слоя принимаем только основную аннотацию версии издателя в JATS при явной лицензии CC BY 4.0 или CC0 1.0 в записи. Сверяем DOI и PMC ID с JATS, сведения об издании с OpenAlex и заголовок после нормализации. Сохраняем авторов, запись об авторских правах, формулировку и URL лицензии, адрес статьи и отметку о преобразовании пробелов/разметки. [Условия Europe PMC](https://europepmc.org/Copyright), [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/legalcode.en), [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/).

Сверяем документ по нормализованным DOI, OpenAlex ID, PMC ID, заголовку и SHA-256 нормализованных слов. Для версий ищем совпадения названия, схожесть названий (SequenceMatcher ≥ 0,92 при совпавшем первом авторе либо Жаккар слов ≥ 0,85), аннотаций (Жаккар множеств шинглов из пяти слов ≥ 0,75) и явные связи версий источника, если доступны. Соответствия историческим Corpus30 и Corpus12 исключаем до финальной фиксации. Отклонённые пары документируем. Будущие DEV/holdout и Gold отсутствуют в входах и определяются после утверждения корпуса.

## DESIGN

Детерминированный проход по выдачам по десяти зарегистрированным подгруппам. Первые 40 результатов на запрос, порядок релевантности на момент выгрузки. При нехватке квоты расширяем запрос той же подгруппы с записью причины до очередного запроса. Для каждой строки фиксируем исходное место, факт повторной выдачи, итог решения и причину. Порядок отбора внутри подгруппы — по месту в пуле с явными отклонениями по результатам чтения. Seed не применяется. Используем существующие `OpenAlexClient`, `validate_document` и JSONL-контракт. Версия документа — `sha256:<UTF-8 text>`, ID — короткий OpenAlex ID. Срез источника хранит аннотацию с лицензией и библиографией; весь XML проходит обработку в памяти. Повторная сборка использует замороженные локальные входы и решения. Смена исходного текста или состава требует новой ревизии/среза. Проверка по хешам останавливает восстановление при изменении аннотации на сервере.

До 30 запросов поиска на провайдера и до 400 запросов XML с кэшем; один процесс, до 30 минут на сбор, без платных API и модельных токенов. Стоп при исчерпании квоты, бюджета или отсутствии подтверждённых источников для 100 работ. Публикуем только метаданные, параметры и хеши в новой директории этапа. Тексты лежат в `data/retrieval/benchmark_3a5_11/corpus100/`. Для повтора сборки без локального среза используем лицензированные источники из lock и повторно проверяем хеши.

| Покрытие связками | По одной проверенной паре на подгруппу и ≥4 межтематических пар, покрывающих все темы; provenance и точные offsets |
| Воспроизводимость | Повторная сборка побайтно, сверка SHA-256 файлов и каждой строки, проверка исходного контракта и нарезки evidence по Unicode code points |

Считаем слова через `str.split()`. Токены для статистики — Unicode Regex v1 (`\w+|[^\w\s]`, Python 3.11, без спецтокенов и весов). Показываем суммы, min/median/mean/p95/max (p95 по ближайшему рангу), гистограммы слов и лет. Для смысловых пересечений приводим пары со ссылками на аннотации и интервалы подтверждающих фрагментов. Это описательные показатели для целевой выборки без доверительных интервалов.

В этом этапе отсутствуют создание графа, NER/RE, embeddings, вопросы, Groq, Airflow, изменение namespace, frozen C и исторических результатов. Риски для сравнения — тематический и лицензионный перекос, разная длина аннотаций, терминологическое сходство разных задач, неизвестное присутствие работ в предобучении LLM и ограниченная сопоставимость цифр между статьями.

## Уточнение источника от 2026-11-24

После тайм-аутов Europe PMC для XML используем официальные версионированные объекты [PubMed Central Cloud](https://pmc.ncbi.nlm.nih.gov/tools/pmcaws/). Europe PMC остаётся каталогом кандидатов. Проверяем список версий по PMC ID и метаданные JSON. Требуем единственную издательскую версию, соответствующие DOI и PMC ID, доступность в OA, отсутствие отзыва и совместимый архивный код лицензии. Точный URL лицензии устанавливаем по JATS. Сохраняем адреса и SHA-256 JSON и XML. Один процесс с четырьмя параллельными HTTP-запросами к публичному хранилищу, при неизменных текстовых и лицензионных критериях. После тайм-аутов составного запроса о фотоэлектрических прогнозах используем точную фразу `photovoltaic power forecasting`. Базовый запрос о биогазе охватывает сочетание `microalgae` и `anaerobic digestion`.

После проверки тематического покрытия расширена одна подгруппа энергетики до анаэробной переработки микроводорослей и биогаза. В ней сопоставляются получение и очистка биогаза, а также два эксперимента с альтернативным выходом органических кислот. Это позволяет различать стадии и цели процессов. Квоты пяти тем сохранены. Расширения поисковых выражений и их основания зафиксированы в `query_extensions.json`.
