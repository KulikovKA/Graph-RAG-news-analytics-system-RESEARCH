# Corpus100 · Stage 3A.5.11.1

Срез `3A.5.11.1-corpus100-v1` содержит 100 англоязычных издательских аннотаций. Все тексты имеют CC BY 4.0 с явной записью в JATS и привязаны к конкретному объекту PubMed Central. Исходные строки сохранены в Git-исключённом `data/retrieval/benchmark_3a5_11/corpus100/abstracts.jsonl`. SHA-256 файла — `7c761626906e27ddd6d32570ca934f41b5367996b90ceb0696435bfcc5898f96`. В [document_lock.json](document_lock.json) записаны DOI, OpenAlex ID, PMC ID, название, год, тема, авторы, URL, атрибуция, версия архива, хеши источника и ревизия текста. Поле `text` в JSONL содержит аннотацию в исходном контракте `ner-v2-source-1`.

## Отбор и тематические связи

Тринадцать запросов Europe PMC дали 432 позиции, 412 кандидатов после сведения повторных выдач по DOI, PMC ID или названию при отсутствии идентификаторов. Отобраны 100, не вошли 312. Среди 332 невыбранных позиций 149 отклонены по лицензии архива или JATS, 56 по типу, языку или статусу отзыва в OpenAlex, 17 по результатам содержательной проверки, 20 — повторные выдачи, 68 — позиции, прошедшие формальные проверки и оставленные вне квоты. Остальные 22 относятся к идентификаторам, версии издателя, метаданным издания, типу или языку JATS и наличию однозначной аннотации. Проверки ID, DOI, нормализованного названия, хеша текста, сходства названий и шинглов и доступных указаний на версии дали ноль совпадений внутри среза и с историческими Corpus30 и Corpus12.

В журнале 10 внутригрупповых и 6 межтематических пар, по два проверенных фрагмента на пару. Они фиксируют общие методы, данные или технологические связи, которые читаются в исходных аннотациях. Например, CheXpert и CheXbert объединяют работу по классификации рентгенограмм с проверкой извлечения меток из MIMIC-CXR. Тепловизионные горячие точки и аномалии временных рядов связывают диагностику фотоэлектрических модулей с прогнозом мощности. Исследования Chlorella связывают производство липидов из сточных вод с выходом биометана. Другие связки покрывают NER как источник признаков, внешнюю переносимость и применение целлюлазы к разным субстратам. Подробности и evidence offsets — в [selection_audit.json](selection_audit.json).

## Воспроизведение

Из корня репозитория в подготовленном Python 3.11 окружении с `requests` и `tqdm`.

```powershell
uv run --no-sync python reports/retrieval/benchmark_3a5_11/corpus100/prepare.py restore
uv run --no-sync python reports/retrieval/benchmark_3a5_11/corpus100/prepare.py verify
```

`restore` в чистом checkout использует только 100 зафиксированных версий источника из lock. Восстановление останавливается при расхождении аннотации или атрибуции. При наличии локального JSONL команда проверяет его хеш. `build` использует сохранённые локальные `pool_*.json` и `sources/*.json` вместе с [решениями отбора](review_decisions.json), без повторной загрузки. Состав текущей выдачи API меняется. `acquire` полезна для сохранения снимков кандидатов и не служит способом воспроизвести прежнюю выдачу. Запросы, время, версии программы, хеши и адаптация источников записаны в [acquisition_provenance.json](acquisition_provenance.json). Даты относятся к срезу API, а год статьи берётся из OpenAlex.

При переносе текстов сохранять атрибуцию из lock и отметку о преобразовании JATS в текст с NFC и нормализацией пробелов. Один и тот же SHA-256 закрепляет текст для будущей загрузки и evidence offsets. Все интервалы задаются полуоткрытым диапазоном Unicode code points `[start, end)` относительно поля `text`. Для последующего построения графа можно читать JSONL существующим `cgraph.ner_v2.io.read_documents` и связывать будущие evidence с `document_id` и `revision_id`. [План этапа](../../benchmark_3a5_10/STAGE_3A5_11_PLAN.md).

## Ограничения сравнения

- Выборка целевая. 76 работ вышли в 2024–2025 годах, у 36 в JATS издателем указан MDPI. Источники PMC и фильтр CC BY 4.0 влияют на покрытие площадок. Подгруппы ML, CV и NLP пересекаются на клинических задачах.
- Схожие методы, исходные наборы и термины создают трудные отрицательные примеры. Совпадение названия метода или датасета само по себе не подтверждает фактическую связь. Цифры сопоставимы только при учёте различий в метриках, условиях и данных.
- Подгруппа биоэнергетики включает получение и очистку биогаза, а также работы, где анаэробная переработка направлена на выход органических кислот. Не все работы измеряют выход метана.
- Аннотации ограничивают доступные детали и могут содержать издательские служебные строки. Токенизация описательная и может отличаться от токенизатора будущего LLM. Публичность источников допускает запоминание в предобучении, степень которого неизвестна.
- Проверка версий ограничена доступными идентификаторами, ссылками и порогами сходства. Сильно переписанные внешние версии без общей метаинформации могут остаться незамеченными.
