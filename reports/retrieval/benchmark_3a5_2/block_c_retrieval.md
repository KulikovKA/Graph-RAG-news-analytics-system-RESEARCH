# Stage 3A.5.2 — первый retrieval benchmark блока C

## Результат

Технический smoke — **PASS**. Стандартные компоненты retrieval завершили **10/10** запросов к live Neo4j с документированной экспериментальной политикой query linking. Полный reference set попал в Top-5 у **2/10** вопросов (C04, C10). Средний `GoldDocRecall@5` составил **61,7%**. Из 21 требуемого появления документа по всем вопросам **18** встретились в путях-кандидатах, **13** попали в Top-5 и те же **13** имели хотя бы одно ребро с валидным provenance.

Из 44 обязательных Gold-фрагментов **26** пересекались с окнами выбранных фактических рёбер, **1** подтвердил полный Gold-факт вместе с семантикой ребра. Суммарный `EvidenceCoverage@5` — **1/44 (2,3%)**, макросреднее по вопросам — **1,4%**. Для пересечения окон показатели составили **26/44 (59,1%)** и **58,9%** соответственно. В 2 000 кандидатах было **84 пути с переходами между документами** и **0 путей с provenance-валидными фактами из двух документов одновременно**. В Top-5 из 50 путей междокументных фактических путей также нет.

[Структурированные результаты](block_c_retrieval.json) содержат mentions с offsets и типами, кандидатов linking со score и рангами, seeds и причины отсечения, пути и типы рёбер, переходы с ключами узлов, точные окна с provenance, Top-5 со score и его компонентами, исключения, поэтапную latency и разбор каждого Gold-фрагмента. Кандидаты за пределами первых пяти на mention не выдаются интерфейсом линкера.

## Диагностика

Первую стадию потери определяли по пропущенному в Top-5 документу. Для восьми пропусков получено распределение **5 reranking, 2 entity linking, 1 KG**. Однозначных первичных пропусков на query analysis, BFS или evidence extraction в этом прогоне не установлено. Все десять обходов упёрлись в `max_candidates=200`, поэтому отсутствие маршрута в пуле само по себе не доказывает отсутствие маршрута в графе.

| Первая стадия | Вопросы | Наблюдение |
|---|---|---|
| Reranking | C01, C02, C05, C06, C08 | Соответственно 115, 144, 39, 12 и 19 путей с provenance-валидным фактом из пропущенного документа получили `outside_top_k`. |
| Entity linking | C03, C07 | Узлы W2039836112 и W2326480042 есть в KG, но отсутствуют в выданных кандидатах линкера по всем mentions соответствующего вопроса. |
| KG | C09 | Нужный узел прошёл cutoff и дошёл до BFS, но у него нет допустимой смежности. |

Три случая показывают разные механизмы потери.

- **C02. Reranking.** `dialysis patients` найден GLiNER и точно связан с узлами W2761455282. Из 168 кандидатных путей этого документа 144 содержат его provenance-валидные факты. В частности, путь `1cb3165e…` включает связь артропластики с медицинскими осложнениями и пневмонией. Все пять выбранных путей относятся к rHuEPO. На первом месте (`2.694009`) сравнение с engineered proteins. Оно получило высокий score за лексику окна полного abstract.
- **C03. Entity linking.** GLiNER выделил `gene expression` и `genetic perturbations`. В W2039836112 есть `Px1 knockdown` и `Cx43 knockout mice`, но в пяти выданных кандидатах на каждое упоминание нет узлов из этого документа. Лимит входа BFS отсёк три seed-кандидата из других источников. В Top-5 подтверждён M3 из W2076293586 по ребру `gene expression — COMPARED_WITH — CNV` и предложению `[946,1064)`. Осторожный вывод M4 об отсутствии простой корреляции во всех случаях в выбранных фактах отсутствует.
- **C09. KG.** `optical fibers` связан с `coherent fiber optic bundle` из W2084709926 (cosine `≈0.904`). У seed есть входящее `RELEX_MENTIONS` и петля `SIMILAR_TO` с решением `MERGE`. BFS корректно исключил оба ребра. На других узлах документа есть 36 `RELEX_REL`, но доверенных междокументных мостов к этому документу нет. Повышение бюджета BFS для этого seed не создаст смежность.

C04 и C10 иллюстрируют разрыв между покрытием документов и фактов. У обоих вопросов все обязательные диапазоны содержались в provenance-валидных окнах Top-5. Выбранные рёбра не подтверждали целиком ни одного обязательного утверждения. Например, ребро C10 про изготовление медалей при `sede vacante` не выражает их функцию как инструмента создания образа папы. Для C06 два валидных по provenance ребра связывают осложнения и улучшение как причину и результат. Frozen-абстракт сообщает эти наблюдения отдельно.

Оценка `EvidenceCoverage@5` выполнена одним ручным проходом после retrieval. Для зачёта требуется, чтобы смысл ребра и его endpoints вместе с frozen-источником подтверждали полный обязательный claim. Совпадение SHA, offsets и текста окна проверяет происхождение цитаты. Смысл факта оценивается отдельно. `SIMILAR_TO` и `HAS_SHARED_CONCEPT` использованы как навигация и не засчитаны как evidence.

```powershell
$env:HF_HUB_OFFLINE = '1'
$env:TRANSFORMERS_OFFLINE = '1'
python -B reports/retrieval/benchmark_3a5_2/validate_draft.py
python -B scripts/smoke_retrieval_3a5.py --question 'What is reported about follow-up?'
python -B reports/retrieval/benchmark_3a5_2/run_block_c.py --min-score 0.85 --output reports/retrieval/benchmark_3a5_2/block_c_repeat.json
```

[Runner](run_block_c.py) заново вычисляет пути, score, покрытие документов и пересечения offsets. Для повторной оценки точных фактов и первичных потерь используются сохранённые в JSON ручные adjudications, source triple IDs, решения реранкера и отдельная read-only сверка смежности.
