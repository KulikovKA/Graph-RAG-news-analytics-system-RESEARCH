# Stage 3A.5.6 — BFS budget sweep и Seed-Fair BFS

## Методика

Десять утверждённых вопросов блока C. Фиксированные top‑5 кандидатов линкера на mention взяты из Stage 3A.5.2. Cutoff 0.85 воспроизводит исходные seeds до применения max_seeds. Сравнение порогов повторно фильтрует тот же список кандидатов по сохранённым cosine scores. Во всех строках использован реранкер A с Top‑5. Gold применяется при оценке результатов.

BFS работает с проверенным read-only снимком Neo4j. Базовые порядок path IDs и Top‑5 совпали с историческим live-прогоном по всем десяти вопросам. Время в таблице измерено на снимке. Nodes/edges read — суммы прочитанных строк по десяти запросам, включая повторные чтения. Candidate Recall и Top‑5 Recall — макросредние по вопросам. Factual Candidate Recall учитывает provenance-валидные факты. «Вне Gold docs» — приближение к нерелевантности по документам. Gold для части вопросов неисчерпывающий, а факт из Gold-документа может не отвечать на вопрос.

A кидает уникальные seeds в общую FIFO в порядке линкера и добавляет потомков по ключу ребра и соседнего узла. B держит FIFO на seed и выдаёт до одного кандидата за ход по отсортированным ключам seeds. Если расширение не выдало кандидата, ход передаётся дальше. Оба режима считают строки смежности общим лимитом. При бюджете меньше числа продуктивных seeds или при раннем исчерпании строк гарантировать путь для каждого seed невозможно. Режим C не тестировали, так как приоритизация по score добавила бы ещё один фактор к проверке fairness.

## C09

Seed `coherent fiber optic bundle` (cosine ≈0.904, W2084709926) имеет 0 исходящих и 0 входящих `RELEX_REL`. На остальных узлах W2084709926 найдено 36 `RELEX_REL`. Для seed `RELEX_MENTIONS` вне разрешённых типов, а петля `SIMILAR_TO` отбрасывается проверкой цикла и имеет решение `MERGE`. У этого seed отсутствует допустимое первое ребро. Ни повышение лимита, ни смена расписания обхода не создают продолжение.

```powershell
$env:PYTHONPATH = "src"
python reports/retrieval/benchmark_3a5_2/run_bfs_budget.py --output sweep.json
python reports/retrieval/benchmark_3a5_2/run_bfs_budget.py --bolt-reference sweep.json --output bolt.json
```
