# Stage 3A.5.4 — Fact-aware reranking и production

**В production по умолчанию выбран C.** Политика C2 лучше отфильтровала посторонние документы в контролях и сохранила важное ребро на историческом C06. Она потеряла пять Gold-привязок на утверждённом блоке и две на holdout относительно C. В утверждённом блоке у C2 также больше рёбер с неподтверждённым смыслом, несмотря на меньшее число посторонних источников. В соответствии с принятым решением C сохраняет преимущество по полноте, с задокументированными ограничениями.

[Офлайн-сравнение A/C/C2](c2_comparison.json) · [Смысловой аудит](c2_semantic_audit.json) · [Production replay и fallback A](c2_production_replay.json).

## C2

- **Entity relevance.** Нормализованные термины вопроса сравниваются с именами физических head и tail. Для имени проверяются ключ, `entity_id`, документ, namespace и fingerprint. Без надёжного контекста этот сигнал равен нулю. Opaque IDs и similarity на нефактических рёбрах не входят в score.
- **Predicate relevance.** Группы предикатов получают бонус только при соответствующем лексическом сигнале в вопросе и совпадении хотя бы с одним термином концов ребра. Например, вопрос о результате может усилить `HAS_RESULT`. Предикатная эвристика не устанавливает правильность направления, атрибуции или полярности.
- **Local evidence relevance.** В provenance-валидном окне выбирается предложение с привязкой к именам физических концов. Два совпадающих конца дают полный локальный вес, один — 35%. Сохраняются исходный `window_id`, `source_triple_id`, revision, SHA-256, цитата и абсолютные Unicode offsets. Исходное окно и evidence bundle доступны целиком.
- **Отбор.** Веса трёх сигналов зафиксированы на `1.8 / 0.35 / 1.1`. В score пути входит сильнейшее ребро, прежнее покрытие полного окна с весом `0.45` и прежние linking, hop, provenance и repetition-сигналы. После первого слота бонус нового фактического документа не больше `0.30` и доступен только при локальном сигнале от `0.40` и base score в пределах `0.70` от лидера. Вес Jaccard снижен до `0.20`. Параметры после оценки не подбирались.

## Сравнение

Все три политики для каждого из **35** вопросов получили один кандидатный пул. Утверждённый блок воспроизведён на сохранённых seeds с совпадением упорядоченных IDs всех **2 000** путей. Для 10 исторических вопросов и 15 контролей выполнен локальный последовательный GLiNER/E5. Настройки моделей, cutoff `0.85` для E5, traversal limits и версии Gold взяты из [предыдущей проверки](validation_report.md). Использован read-only адаптер хеш-совпадающего frozen-снимка `ba06b63dfba69c4a930101426934c717b733257daf91309b6bb7ecb99ebcc1dc`. Новый live Neo4j-прогон в измерениях отсутствует. Top-5 A и C на всех 35 вопросах точно совпали с предыдущей проверкой, включая scores и provenance. Ни один Gold ID или ответ не передавался ранжированию.

## Смысловой аудит

Проверены все **193 изменившихся фактических ребра** и **80 общих**. Единица подсчёта — физическое ребро на один вопрос. Рёбра с одинаковым смыслом могут иметь разные IDs. Аудит отдельно оценивал пользу для ответа и соответствие отношению в источнике. Пересечение offsets и lexical score в смысловой зачёт не входят. Во второй таблице считаются вытесненные рёбра, включая случаи, где другое ребро выражает тот же компонент.

- **Утверждённый C02.** C и C2 сохранили оба Gold-документа. C2 выбрала более уместный контекст об артропластике у диализных пациентов и связи rHuEPO с CKD. Оба факта о рисках остаются неполными. C добавила посторонний пилот радиотерапии с неподтверждённым ребром о malfunction.
- **Утверждённый C05.** C2 вернула W2906067930 без постороннего документа, но потеряла W4309030044. Отдельные рёбра о demand line завышают утверждение источника о направлении связи. Ни одна политика не собрала оба документа и оба нужных факта.
- **Исторический C06.** C2 сохранила `Mammographic density — DEPENDS_ON — reader` (W1979727947 `[14,152)`). C его вытеснила. У C2 остался один посторонний документ об ERM.
- **B01, B03, B06.** C2 устранила четыре посторонних документа, которые добавила C, при сохранении всех 15 Gold-документов по контролям. Внутри единственного документа она ещё может повторять один source triple в разных путях и вытеснять полезный контекст.
- **Исторический C10.** `author — PERFORMS — listening` у C помечено как неподтверждённое. W7215137876 `[611,789)` описывает слушание как синодальную практику, которую автор обсуждает. C2 это ребро не выбрала в данном прогоне. Лексические эвристики сами по себе не умеют надежно отличать обсуждение от выполнения действия.

## Итоговый production replay

Вызов `rerank_paths(...)` без параметра выбирает **C**. `policy="A"` возвращает прежний алгоритм, который также доступен по имени `rerank_paths_a`. `policy="C2"` выбирает экспериментальный режим. Для его полного score вызывающий код передаёт проверенные узлы как `entity_nodes`. [Runner live baseline](../run_block_c.py) принимает `--reranking-policy A|C|C2` и передаёт проверенный snapshot-контекст для C2. Для воспроизведения исторического отчёта следует явно выбрать A.

Production C и fallback A повторили офлайн-результаты утверждённого блока на идентичных входах. Совпали path IDs, баллы, компоненты баллов, исходные триплеты, окна и метрики всех десяти вопросов. Детерминированность проверена перестановкой кандидатов во всех режимах и полным повтором 35 вопросов на итоговом коде с другим `PYTHONHASHSEED`. Проверено **188 локальных фрагментов C2** по исходным текстам, revision, хешу и идентификаторам окон. Прошли **147 тестов** retrieval, evidence и reranking. Общий gate использует существующие идентификаторы, trust flags и provenance. Исходные направления фактов и frozen snapshot сохранены.

## Что остаётся

C повышает полноту поиска, сохраняя установленный выигрыш относительно A. Ограничения для последующей агрегации — посторонние документы у multi-hop контролей, рёбра с валидным provenance и неподтверждённым смыслом, три Gold-документа вне утверждённого пула и один доступный документ W2906067930 ниже Top-5. [Контракт Evidence Aggregation](evidence_aggregation_design.md) предусматривает независимые source triples, проверку смыслового покрытия и сохранение невосполненных аспектов.
