# Stage 3A.5.3 — Проверка перед внедрением политики C

**Решение `KEEP_EXPERIMENTAL`.** На историческом holdout C поднял recall документов с **16/20 до 18/20**. В single-document контролях обе политики сохранили **15/15** эталонных документов и **34/34** пересечений окон. C добавил четыре проверенных вручную посторонних документа в трёх контролях и вытеснил часть полезного контекста. На holdout пять добавленных рёбер оказались посторонними, одно — неполным, одно — не подтверждено источником. Одно прямо нужное для ответа ребро пропало. Этого достаточно, чтобы сохранить A как действующий production reranker. Переключение на C и отдельный fallback не вводились.

## Условия прогона

- Использованы исходные A и C из `123f7f4237a7ddc5cb6506f402d6044c4889d446`. SHA-256 файла C `ec077c482c3a4c15ee5a627f8efda4208b07cdd0a77b069325578603fbcd131b`. До отбора зафиксированы ненулевое совпадение терминов, отставание base score до `1.0`, бонус независимого второго пути до `0.15` и три первых слота для лидеров документов.
- Bolt отвечал, но требовал аутентификации. В процессе отсутствовали настроенные учётные данные. Использована локальная копия frozen snapshot в памяти, собранная штатным способом из зафиксированного снимка предшественника и готовой дельты. Проверены SHA-256 полного снимка `ba06b63dfba69c4a930101426934c717b733257daf91309b6bb7ecb99ebcc1dc`, fingerprint `41901f76e83ee9ab65fedfba888790504c8f328066a319115fcb6f13f7c3525a` и тексты всех документов. Namespace `relex_sem_e5_small_name_t095_ner_t046_er2f3_concept_v2_sem_name_t0830`.
- Адаптер в памяти отвечает только на четыре фиксированных read-запроса. Использованы исходные `GraphRetriever.retrieve` и `EvidenceExtractor.extract` с теми же лимитами и trust-правилами. На архивных seeds утверждённого C совпали **2 000/2 000** кандидатов в исходном порядке, диагностика обхода, evidence и **50/50** рангов A, включая scores и исключения. Транспорт и сетевой timeout в этом эксперименте отдельно не оценивались.
- Для 25 новых вопросов последовательно выполнены реальные GLiNER и E5 с теми же локальными весами, GLiNER cutoff `0.15`, E5 cutoff `0.85`, пятью кандидатами на mention, seed Torch `42` и четырьмя CPU-потоками. Лимиты BFS составили 5 hops, 50 neighbours, 200 candidates, 1 000 relationships и 32 seeds. Gold передан только оценке после отбора. Отдельный production- и live-прогон не проводился.
- A и C разделяли один кандидатный пул для каждого вопроса. Полный повтор с другой солью Python воспроизвёл все 25 свежих и десять архивных случаев, включая path IDs, scores, profiles, source triples, окна и метрики. Wall times менялись. Дополнительно на каждом вопросе проверена перестановка путей. Прошли **140** профильных тестов.

## Смысловой аудит

Один ручной проход по **45** различающимся фактическим рёбрам в A/C. Для каждого проверены предикат, концы ребра, исходный текст и требуемая часть вопроса. Повторно выбранные рёбра сохранили свою семантику и источник. Положительное пересечение окна не использовалось как зачёт факта. Суммарное смысловое покрытие всего ответа осталось `NOT_EVALUATED`.

| Набор и разница | Прямой компонент ответа | Неполный контекст | Постороннее | Связь не подтверждена |
|---|---:|---:|---:|---:|
| Holdout, только A | 1 | 2 | 1 | 3 |
| Holdout, только C | 0 | 1 | 5 | 1 |
| Контроли, только A | 0 | 4 | 0 | 0 |
| Контроли, только C | 0 | 1 | 4 | 0 |
| Утверждённый C, только A | 0 | 4 | 5 | 2 |
| Утверждённый C, только C | 1 | 1 | 7 | 2 |

- **Исторический C06.** A вернул `Mammographic density — DEPENDS_ON — reader` с W1979727947 `[14,152)`. C вытеснил его путями о rHuEPO и ERM. Покрытие окон при этом осталось **2/3**.
- **Исторический C08.** C вернул W2039836112 и ребро `knockdown — APPLIED_TO — astrocytes`. Оно передаёт часть метода, но опускает Px1, siRNA и разграничение с фармакологическим тестом и Cx43 knockout. Дополнительный путь о дрожжевой инженерии не относится к указанным экспериментам.
- **Исторический C10.** C вернул W7215137876, но ребро `author — PERFORMS — listening` неверно приписывает практику автору. В `[611,789)` автор сопоставляет синодальные практики с внутренней работой IFS.
- **B01, B03, B06.** C добавил маммографию и сенсорные сети к детекции людей, rHuEPO к оценке маммографической плотности и авиажелезнодорожные тарифы к вопросу об IFS. У B03 из выдачи выпало относящееся к оценке breast cancer risk ребро о logistic regression. У B06 пропал контекст IFS, хотя Gold-документ остался.
- **Утверждённый C08.** Добавлен прямой компонент про эмоциональную зрелость в синодальном контексте из W7215137876 `[0,180)`. Другие восстановленные документы в утверждённом наборе не гарантировали восстановления нужного утверждения. В C01, например, путь про происхождение лимфоцитов не устанавливает подавление T-клеточной активности.

Больше документов помогло на двух исторических вопросах. Утрата прямого компонента ответа C06 и посторонние источники в трёх single-document контролях дают основания для `KEEP_EXPERIMENTAL`. Production-файлы имеют исходные версии. Отдельная последующая проверка может оценить отбор по релевантности предиката и концов ребра с явной защитой single-document вопросов. Параметры C в этом прогоне остались зафиксированными.

## Воспроизведение

Запустить из корня в Python 3.11 с локальными зависимостями, frozen кэшем и моделями. `--parity-only` воспроизводит архивный baseline без моделей. Основная команда выполняет локальный CPU-инференс и измеряет holdout и контроли.

```powershell
python -B reports/retrieval/benchmark_3a5_2/validate_promote_c/run_validation.py --output validation_repeat.json
python -B -m pytest tests/test_retrieval_types.py tests/test_query_analysis.py tests/test_entity_linking.py tests/test_graph_retrieval.py tests/test_evidence_extraction.py tests/test_path_reranking.py reports/retrieval/benchmark_3a5_2/test_document_aware_reranking.py -q
```

Контракт будущей агрегации хранит отдельные исходные триплеты, привязки к аспектам вопроса и точные источники. Спецификация и план тестов сохранены отдельным документом. Прототип предстоит проверить на Gold.
