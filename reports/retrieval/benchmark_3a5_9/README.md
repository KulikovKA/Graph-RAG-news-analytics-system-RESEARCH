# Stage 3A.5.9 · проверка предела Graph-RAG retrieval

**Решение KEEP_C.** Изменение linking Top-K с 10 до 5 при FIFO, 100 кандидатах и штатном C вернуло один дополнительный обязательный документ на 25 approved-вопросах. FactualGoldDocRecall@5 вырос с **32/36 до 33/36**. Прирост целиком относится к C05. Новая формулировка C05 его устранила. На B01 и C08 появились два проверенных посторонних источника. Критерии замены production не выполнены. Для будущей генерации зафиксирован профиль с K=10. ### Где теряются документы

Для каждого пропуска проверены corpus membership, сущности и физические факты графа, все исходные mentions с диапазонами, лучший cosine и ранг в каждом mention, seeds до/после cap, сырые пути, валидные factual пути, первый ранг в префиксе и Top-5. Диагностический поиск свидетеля снимает ограничения строк и кандидатов, сохраняя пять физических переходов и production trust rules. Ветка отсекается только по нижней границе длины на графе, включающем все допустимые переходы. Проверка каждого достигнутого целевого факта проходит штатный extractor. ### Время, память и границы оценки

На snapshot replay использованы Python 3.11.9, локальный read-only адаптер, одна последовательная очередь. GLiNER и E5 работали отдельно для шести новых формулировок и недостающих строк E5, 4 CPU-потока, seed 42. Высшая RSS процесса подготовки моделей составила 2.12 GiB (2 271 076 352 байта). Матрица достигла 457.2 MiB (479 412 224 байта). RSS в строках — накопленный максимум процесса Windows; его нельзя интерпретировать как дополнительную память конкретной эвристики. Производительный индекс содержит 557 вершин. Построение индексов фактической степени и BM25 в lexical run заняло 16.7 мс суммарно.

Перцентили интерполируются по 25 вопросам. Замеры включают работу с исходными cosine, traversal, evidence, C, и для префиксных вариантов — дополнительный scoring и выбор. Чтение кэшей, расчёт метрик, загрузка snapshot, NER/E5 и сетевой Bolt вынесены за пределы этих замеров. В строках есть время исходных стадий NER/E5 и верхняя оценка дополнительного encoding фрагментов. Общий процесс прогревается, порядок политик фиксирован. Из разницы в несколько мс нельзя заключать об ускорении deployment. [Поэтапные времена по вопросам](results/matrix/questions.jsonl)
