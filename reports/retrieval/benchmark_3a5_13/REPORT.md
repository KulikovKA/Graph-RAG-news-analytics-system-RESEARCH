# Stage 3A.5.13 · Fine-grained EE threshold sweep

Corpus100. Завершено конфигураций — **528**. Режим — полный перебор.

Пара из разных документов проходит при одновременном достижении обоих порогов. Столбцы `pure` показывают результаты до защит, `guarded` — после защит Stage 3A.5.12.

Покрытие — доля всех канонических сущностей или документов с хотя бы одной EE-парой. Для тематических долей знаменатель ограничен тематикой. Межтематическая пара учитывается один раз. Статистика степени включает изолированные сущности, стандартное отклонение рассчитано по всей совокупности, квантили используют линейную интерполяцию. Размер закрытого окружения — число непосредственных соседей плюс сама сущность, включая одиночные окружения.

Диагностика повторяет канонические EE-сопоставления 20 исторических случаев, включая исторический референт для записей EC. Диагностика описывает прохождение фильтра.

В таблице пороги name/context — 0.90/0.90. Графики зависимости показывают сечения по каждому порогу через эту точку. Распределения на графиках соответствуют этой точке, а CSV содержит всю сетку.
