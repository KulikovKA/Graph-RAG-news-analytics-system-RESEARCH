# Stage 3A.5.11.2 · Corpus100 KG

Гипотеза — зафиксированная конфигурация Stage 2G.3 позволяет построить на всех
100 аннотациях граф с проверяемыми offsets и хотя бы одним междокументным
семантическим ребром или путём через общий концепт. Контроль для учёта —
внутридокументный RE-граф с теми же вершинами до добавления семантики и концептов.
Исторический Stage 2G.3 задаёт конфигурацию и семантику. Его размеры принадлежат
другому корпусу. Качество извлечения, retrieval и статистическая неопределённость
не оцениваются. Альтернативные пороги и модели исключены из этого запуска.

## Вход и конфигурация

- Только лицензированные опубликованные аннотации и метаданные из [заморозки Corpus100](../../reports/retrieval/benchmark_3a5_11/corpus100/SPEC.md), коммит `750d03a801fd771879b956cdc32324404e72ce57`. `prepare.py verify` перед обработкой; при отсутствии текста — `restore` и проверка. Corpus100 является входом для построения графа. Gold, вопросы, DEV/CAL/HOLDOUT retrieval и профиль C не используются для inference, отбора или настройки.
- [E3](../../reports/ner_v2/research_run2/E3/config.json) · GLiNER 2.5 Base `54785d51df8d86a0d8f2eb212fec15871aad2c4d`, CPU FP32, seed 42, N3, 110 слов с перекрытием 25, 512 токенов, исходные 11 меток, decoder 0.15 и фильтр 0.35. Один span может содержать несколько типизированных mentions.
- [RelEx Base](../../reports/re_v2/relex_comparison/threshold035/e3_base/experiment_config.json) · исходные ontology v2 predicates, explicit-span head, пара исторических токенизаторов для идентичного оконного ограничения, 512 токенов, перекрытие 0.25, порог 0.35. Вес только Base; файлы фиксируются SHA-256.
- [Консервативный ER](../../reports/entity_resolution/relex_base_t035/global_kg_2f3/manifest.json) · общий проход по всем документам. Решения 1B/2F.3 основаны на ручных списках конкретных Corpus30 offsets и aliases. Для новых текстов положительный автоматический случай — исходное однозначное определение short/long form с точными offsets, одинаковым одиночным типом и целыми spans. Остальные возможные совпадения сохраняются отдельными contextual entities. NFC/casefold используется в exact-аудите; имя, тип и сходство сами по себе тождества не устанавливают. Cross-document identity требует отдельного свидетельства; в этом переносе допустимый положительный случай ограничен исходным документом.
- Порядок как в 2F/2G · точные span-узлы → консервативный exact-аудит → E5 `text_name`/0.95 и induced subgraph по `max_member >= 0.46` → remap endpoints после дополнительного разрешения идентичности с сохранением исходных рёбер, параллельных связей и петель → динамический Shared Concepts → [Hybrid C](../../reports/entity_resolution/relex_base_t035/semantic_concept_sweep_extended/manifest.json). Так как автоматических case-specific MERGE 1B для Corpus100 нет, явно доказанные сокращения разрешаются на этапе ER после отбора вершин. E5-small-v2, закреплённый SHA-256, `query: `, masked mean, L2, 512 токенов, batch 8, FP32. Для семантики FP32 dot product, для Hybrid C проверенные float64 cosine и порог 0.830, top-20 entity/entity (union directed top-k), top-10 entity/concept, все пары от 0.950, lexical validator delta, без транзитивного вывода. Для новых концептов нужны подтверждения из двух документов. Memberships класса `cell` из Hybrid получают флаг проверки, как в импорте 2G.3.

## Выполнение и восстановление

Выход `artifacts/corpus_graph_3a5_11`, namespace `relex_corpus100_stage_3a5_11_v1`. Публикуются код и агрегаты. Neo4j записывает только проверенный payload этой сборки. Лимит памяти Neo4j 716,8 МиБ потребовал ограниченных транзакций. Перед записью проверяются все существующие ключи, свойства, концы рёбер и отсутствие межпространственных связей. Продолжение добавляет отсутствующие объекты. После записи выполняется полное чтение, сверка хеша остальных пространств и контрольный повтор. До успешного чтения namespace считается незавершённым. Вход и конфигурация фиксируются в manifest, реализация стадий — в checkpoints. NER и RE идут последовательно, каждый с двумя постоянными CPU процессами по четыре потока при достаточных ресурсах. Embeddings выполняются после освобождения процессов RE. Бюджет — один проход локальных моделей без обучения, генерации, платных API или sweep. Остановка при ошибке целостности входа, несовместимой конфигурации, недостатке ресурсов или ошибке стадии с незавершёнными операциями.

Checkpoint каждого документа или блока пишется сразу через fsync и os.replace. Глобальные стадии сохраняют проверенный результат с хешем входных результатов. Повреждённые записи пересчитываются. В Neo4j текущая транзакция откатывается при сбое, а зафиксированные пакеты проверяются и переиспользуются при продолжении. Новый fingerprint требует нового namespace.

## Приёмка

- `prepare.py verify` и локальная проверка всех model files. Манифест фиксирует версии, хеши и seed.
- Fixture-тесты аварийного завершения процесса после записи одного документа, восстановления, повреждённого checkpoint, пустых результатов, offset/revision mismatch, отказа несовместимой конфигурации, provenance, параллельных связей и self-loops.
- NER mentions — типизированные spans от 0.35. Отношения — сырые предсказания по окнам, уникальные направленные типизированные тройки до разрешения и итоговые рёбра с исходными доказательствами. Числа вершин — raw spans, вершины после 0.46 и после ER. Отдельно считаются SIMILAR_TO, концепты, memberships, междокументные SIMILAR_TO и уникальные пары документов, соединённых напрямую или общим концептом.
- Слабая связность и средняя степень `2E/V` считаются на entities и concepts без RELEX_MENTIONS; петля даёт вклад 2, параллельные рёбра учитываются. Изолированная сущность не имеет ни одного KG-ребра. В отчёте также отмечаются loop-only вершины.
- Live Neo4j · проверка узлов, свойств, ключей, provenance, типов и концов рёбер, отсутствия межпространственных связей, неизменности хеша других namespace и идемпотентности.
- Отчёт фиксирует wall time стадий, выборочный максимум суммарного RSS процесса и workers, фактические проверки, команды и ограничения. Синтетические тесты подтверждают свойства runner, качество корпуса по ним не выводится.
